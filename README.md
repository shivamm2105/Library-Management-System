# 📚 Gyan Library

A modern and responsive Library & Learning Platform designed for students and competitive exam aspirants. The platform provides library information, book showcases, study resources, an interactive quiz system, performance tracking, and a user-friendly experience across all devices.

## 🌐 Live Demo


## 🚀 Features

### 🏛 Library Information

* Modern Hero Section
* Responsive Navigation Bar
* Library Details & Facilities
* Contact Information

### ⭐ Library Features

* 24×7 Study Environment
* High-Speed WiFi
* Air Conditioned Reading Hall
* Academic & Competitive Exam Books
* Digital Library Access
* Silent Study Zones
* CCTV Security Monitoring
* Personal Locker Facility
* Dedicated Study Cabins

### 📖 Books Showcase

* Book Cards
* Author Information
* Category Display
* Availability Status
* Search Functionality
* Category Filtering

### 🖼 Gallery Section

* Library Interior Images
* Study Environment Showcase
* Responsive Image Layout
* Interactive Hover Effects

### ❓ FAQ Section

* Frequently Asked Questions
* Expand/Collapse Functionality
* Mobile Friendly Design
